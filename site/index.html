Why Tokenmeter

Subscriptions and API budgets together

Plan limits (5-hour sessions, weekly caps, premium requests) and API spend against your monthly budgets, in one place.

What's left, first

Every card headlines its tightest limit (“2h 6m left in session”, “$57.82 left of $100”) and turns red once 80% is used.

Nearest limit on top

Cards sort by how close they are to running out, or drag them into your own order.

Stays out of the way

Pinned, it shows only the cards; hover to bring back the controls.

Local-first and private

Most cards read files your tools already write. No telemetry; keys are encrypted with your system keychain.

Keeps itself current

Updates through apt on Linux, Homebrew on macOS, and automatically on Windows.

Install

Linux

Debian, Ubuntu and derivatives: add the signed apt repository once; updates arrive with your other system updates.

curl -fsSL https://mugeshk97.github.io/tokenmeter/tokenmeter-archive-keyring.gpg | sudo tee /usr/share/keyrings/tokenmeter-archive-keyring.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/tokenmeter-archive-keyring.gpg] https://mugeshk97.github.io/tokenmeter stable main" | sudo tee /etc/apt/sources.list.d/tokenmeter.list
sudo apt update && sudo apt install tokenmeter

Signing key 51E7 3671 79B2 798A B250 5D10 7CFF 9452 0564 EA38.

macOS

With Homebrew (macOS 13 or newer):

brew install --cask mugeshk97/tap/tokenmeter

Or download the .zip from the latest release. Tokenmeter isn't signed with an Apple Developer ID yet, so on first launch open System Settings → Privacy & Security and click Open Anyway.

Windows

Download tokenmeter-…-setup-x64.exe from the latest release and run it. Tokenmeter then updates itself.

The installer isn't code-signed yet, so SmartScreen may warn about an unknown publisher: click More info → Run anyway.

Private by design

  • Your usage data stays on your computer. No analytics, no telemetry.
  • API keys are encrypted with your system keychain (macOS Keychain, Windows DPAPI, GNOME Keyring or KWallet).
  • Each key is only sent to its own provider's API.
  • Open source under the MIT license: read the code.

Frequently asked questions

Is Tokenmeter free?

Yes. Tokenmeter is free and open source under the MIT license.

Does Tokenmeter send my usage data anywhere?

No. Local cards only read files your AI tools already write on your computer, there is no analytics or telemetry, and API keys are only sent to that provider's own API.

Which AI tools does Tokenmeter support?

Claude Code, OpenAI Codex, GitHub Copilot, Gemini CLI and Grok CLI, plus spend and budgets for the Claude (Anthropic), OpenAI and xAI APIs.

Does Tokenmeter work on Linux?

Yes. On Debian, Ubuntu and derivatives, install it from the signed Tokenmeter apt repository and it updates with your other system updates. It also runs on Windows and macOS.

Can Tokenmeter show Claude Code limits as a percentage?

Anthropic doesn't publish a usage-limit API for Pro and Max plans, so Tokenmeter shows the time left in your current 5-hour session, calculated from your local Claude Code transcripts.

Is Tokenmeter an official Anthropic, OpenAI or GitHub product?

No. Tokenmeter is an independent open-source project and isn't affiliated with any of the providers it reads.
